# UNIDAD-1-EJERCICIO-4
Resolución del ejercicio N°4 de la unidad 1 de programación 2.
modela a los pacientes caninos de una clínica veterinaria para registrar su información principal (nombre, raza, edad y peso) y determinar de forma automática si necesitan una revisión médica anual basándose en su edad.
Al final va a mostrar un informe del animal diciendo si necesita o no una revisión.
